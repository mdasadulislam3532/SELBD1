# SELBD Android App

SELBD is a custom Android WebView application featuring:
- In-App Web browsing (Facebook & web)
- Multiple Browsing Modes (Mobile, mBasic, Desktop)
- In-App HTTP Proxy configuration
- 2FA Tool shortcut
- Direct Telegram Bot & Support Channel access
- GitHub Auto-update checking system

## Build instructions
This repository includes a GitHub Actions workflow that automatically builds the debug APK on every push.
You can download the APK from the **Actions** tab artifacts.
